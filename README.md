# Германия: Орёл и Решка

Статический сайт для школьного задания по географии. Он заменяет презентацию и повторяет структуру ТЗ:

- название страны;
- визитная карточка;
- режим «Орёл» с ценами;
- режим «Решка» с экономией;
- необычное правило;
- фотоколлаж;
- 5 вопросов для класса.

## Как открыть

Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `styles.css`, `script.js` и `README.md`.
3. Откройте `Settings` -> `Pages`.
4. Выберите `Deploy from a branch`, ветку `main`, папку `/root`.
5. Через минуту GitHub покажет ссылку на сайт.
